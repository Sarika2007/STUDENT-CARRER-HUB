# Student Career Hub 🎓
### Your Future Starts Here

Student Career Hub is an all-in-one student career development platform designed to help students learn, develop skills, and prepare for their future careers in one place.

The platform aims to bring together career opportunities, placement preparation, study materials, courses, interview preparation, and resume-building resources in a single, student-friendly environment.

## 🚀 Key Features

- 💼 Job and internship opportunities
- 📚 Study materials and learning resources
- 🎯 Placement and interview preparation
- 📝 Resume-building support
- 🎓 Courses and skill development
- 👤 Student dashboard and account management
- 🤖 AI-powered career assistance (planned feature)
- 🌐 English and Telugu support (planned feature)

## 🛠️ Technology Stack

- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** Registration and login functionality

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd student-career-hub
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### 3. Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
node server.js
```

### 4. Configure environment variables

Create a `.env` file inside the backend folder and configure your MongoDB connection string, port, and JWT secret according to your backend code.

Never upload `.env` files or database credentials to GitHub.
